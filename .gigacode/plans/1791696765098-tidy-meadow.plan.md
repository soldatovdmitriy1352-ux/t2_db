# План: Добавление страницы добавления товара со сканированием штрихкода

## Контекст
- **Пакет:** `com.example.t2_db`
- **Язык:** Java 11, minSdk 24, compileSdk 37
- **Текущее состояние:** БД Users, админ-панель, авторизация
- **Новые требования:**
  1. Не-админ при входе переходит на страницу добавления товара
  2. Сканирование штрихкода через камеру
  3. Таблица Products в БД

## Архитектура

```
MainActivity
    ▼
LoginActivity (ФИО + код)
    ├── Админ (Солдатов Д.А., 341) → AdminActivity (управление пользователями)
    └── Не-админ → AddProductActivity (добавление товара + сканирование штрихкода)
```

## Реализация

### Шаг 1: Добавить зависимость ZXing Android Embedded
**Файл:** `app/build.gradle.kts` и `gradle/libs.versions.toml`
- Библиотека: `com.journeyapps:zxing-android-embedded:4.3.0`
- Поддерживает сканирование штрихкодов через камеру
- Версия: 4.3.0 (совместима с minSdk 24)

### Шаг 2: Добавить разрешение камеры
**Файл:** `app/src/main/AndroidManifest.xml`
- `<uses-permission android:name="android.permission.CAMERA" />`
- `<uses-feature android:name="android.hardware.camera" android:required="true" />`

### Шаг 3: Создать модель Product.java
**Путь:** `app/src/main/java/com/example/t2_db/Product.java`
- Поля: `id`, `productName`, `barcode`, `price`, `quantity`
- Конструкторы, геттеры, сеттеры, `fromCursor()`
- `productName` — название товара
- `barcode` — штрихкод (уникальный)
- `price` — цена (double)
- `quantity` — количество (int)

### Шаг 4: Обновить DatabaseHelper.java
**Путь:** `app/src/main/java/com/example/t2_db/DatabaseHelper.java`
- Новая таблица `Products`:
  - `_id` INTEGER PRIMARY KEY AUTOINCREMENT
  - `productName` TEXT NOT NULL
  - `barcode` TEXT NOT NULL UNIQUE
  - `price` REAL NOT NULL DEFAULT 0
  - `quantity` INTEGER NOT NULL DEFAULT 0
- Методы:
  - `addProduct(String productName, String barcode, double price, int quantity)`
  - `getAllProducts()` → Cursor
  - `getProductByBarcode(String barcode)` → Cursor
  - `deleteProduct(String barcode)`
  - `updateProduct(String barcode, String productName, double price, int quantity)`
- `DB_VERSION = 2` (для onUpgrade)

### Шаг 5: Создать activity_add_product.xml
**Путь:** `app/src/main/res/layout/activity_add_product.xml`
- `SurfaceView` для камеры (viewfinder для сканирования)
- `EditText` для названия товара
- `EditText` для цены
- `EditText` для количества
- Кнопка "Сканировать штрихкод" → открывает камеру
- Кнопка "Сохранить" → сохраняет товар
- После сканирования barcode автоматически вставляется в поле

### Шаг 6: Создать AddProductActivity.java
**Путь:** `app/src/main/java/com/example/t2_db/AddProductActivity.java`
- Интеграция с ZXing для сканирования:
  - При нажатии "Сканировать" → IntentIntegrator.initiateScan()
  - Переопределить `onActivityResult()` для получения результата сканирования
  - Вставить отсканированный штрихкод в EditText
- Валидация полей
- Сохранение в БД через DatabaseHelper
- Toast с результатом

### Шаг 7: Обновить LoginActivity.java
**Путь:** `app/src/main/java/com/example/t2_db/LoginActivity.java`
- В методе `OnNext()`:
  - Если админ → AdminActivity (без изменений)
  - Если не админ → AddProductActivity (вместо ошибки)
- Удалить toast "Неверные данные" для не-админа (теперь это нормальный пользователь)

### Шаг 8: Обновить AndroidManifest.xml
**Путь:** `app/src/main/AndroidManifest.xml`
- Добавить `<activity android:name=".AddProductActivity" android:exported="false" />`
- Добавить разрешение CAMERA (уже в шаге 2)

## Верификация
1. Войти как админ → AdminActivity (без изменений)
2. Войти как не-админ → AddProductActivity
3. Нажать "Сканировать" → открывается камера → сканирование штрихкода
4. После сканирования barcode появляется в поле
5. Заполнить название, цену, количество → сохранить
6. Проверить БД: таблица Products с записью
7. Проверить что duplicate barcode не сохраняется
